- FX-IMG-004: グリッド。
- FX-IMG-005: 4000×3000高負荷。
- FX-IMG-006: 64×64。
- FX-IMG-007: EXIF orientation=6 JPEG。

- FX-IMG-009: 色抽出ストライプ。
- FX-IMG-010: 領域ぼかし比較カード。

生成素材は本リポジトリ内で自由に使用・複製・変更可能。第三者フォントは同梱しない。E2EのSVG素材もテストコード内で生成する。
