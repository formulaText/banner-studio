# ライセンス

実際にインストールされた固定バージョンの依存一覧は `dependencies.json`、収録ライセンス本文は `THIRD_PARTY_NOTICES.txt`。
PixiJS、React、Dexie、fflate、Zod等はそれぞれのライセンスを保持。Lucide UIアイコンはISC（パッケージの帰属を本文へ収録）。依存の版はapp/package-lock.jsonを正本とする。

アプリの標準バナー用アイコン・質感・合成フィクスチャはこの開発でコード生成したもの。第三者作品・署名・フォント実体は同梱していない。システムフォントは端末依存。

ユーザーが取り込むフォント・素材は個別の利用条件を確認する。バックアップの素材同梱許諾は初期OFF。Web利用、画像制作、再配布の許諾を混同しない。
