# 開発開始前チェック：外部サービス仕様・実機・未確定事項

版：0.2／2026-11-05　**開発未開始／未確認値を「公式値」と扱わない**。

## 1. サービス別の出力プロファイルを定義する単位
サービス名だけでなく、次のような**用途ごとの別プロファイル**を作る。
- pixivFANBOX：投稿カバー画像（実際の仕様を確認）
- pixivFANBOX：クリエイターページのカバー画像（投稿カバーとは区別）
- X等：リンクを貼った際のカード表示（OGP配信元とSNSキャッシュに依存）
- Fantia / Ci-en：それぞれの画像アップロード場所・SNSシェア時プレビュー
- 自由指定：任意サイズとセーフエリアを持つカスタムプロファイル

**注意**：SNS側のOGP表示は、投稿先が供給するメタタグ・キャッシュ・SNSのカードUIに依存する。バナーツールで画像を作成しても、指定画像が実際にOGPとして使われる保証はない。セーフエリアは目視検証するための編集ガイド。

## 3. サービス実測の記録テンプレート
以下の列をProfileマスターに保存し、**確実性**を表示する。
`profileId,service,purpose,sourceURL,checkedAt,checkedBy,width,height,aspectRatio,fileFormats,maxBytes,previewCrop,uiOverlayPolygons,confidence,notes`

- `confidence`例：`verified_official`（公式記述）、`verified_observed`（画面実測）、`provisional`（検証用）、`unknown`。
- サービス固有の最新UIとデスクトップ/モバイル、未ログイン/ログイン、アプリ/Webの違いを記録。
- SNSカードは特定の日付・プラットフォーム・投稿種別にのみ妥当なガイドとする。将来のUI変更に追随できるようプリセット更新可能にする。
- 実測スクリーンショットは作品情報やアカウント名を不用意に公開しない。匿名テスト素材を使う。
