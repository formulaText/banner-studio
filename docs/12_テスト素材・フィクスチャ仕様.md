# テスト素材・再現データ仕様
版：0.2／2026-11-05。AIが実装時に自力生成する**著作権に問題のない合成素材**の仕様。現時点で完成素材が同梱されているとはみなさない。

## 2. 構図自動調整の検証セット
- `C1`：横長→正方形。顔keepは右上から内側、腰avoidは左下に退出。元角度−20°、固定モードでは変更なし。許可モードでは探索範囲を±15°に限定。
- `C2`：横長→縦長。keep2個、avoid1個。領域の優先度を逆転したとき評価結果が追随するか。
- `C3`：keepとavoidを同じ場所に重ねる。両立不能な場合、違反を隠さずスコア理由を表示するか。
- `C4`：画像の表示領域が斜めの三角形。可視ポリゴンとの交差でkeep面積を評価できるか。
- `C5`：角度変更許可だが許容範囲0°。固定モードと同じ結果になるか。
- `C6`：変更後に手動上書き→プロフィール切替→戻る。調整が保持されるか。
- `C7`：画像が非常に小さい場合。最大倍率制約に違反した配置を勝手に採用しないか。
- `C8`：完全一致が不可能な場合。理由と上位候補を提示できるか。

## 3. 文字セット
- `T1`: 日本語「制作日誌」「全体公開」「成人向け」「支援者限定」。
- `T2`: 「漢字かなカナ ABC 0123」「—・。、！？」「【】」。
- `T3`: 合成アクセントを含むUnicode、絵文字とZWJの組み合わせ、異体字セレクタ。
- `T4`: 改行、長文、空文字、全角空白、絵文字だけ、絵文字＋漢字。
- `T5`: 同じ文字列のフォント切替、未収録文字のあるフォント、ダウンロード失敗。

## 4. テンプレート・データセット
- `D1`: Template 1個、Variant 3種、Project 2件、Profile 3種、共通Asset 4件。
- `D2`: Variant→Projectの色上書き、Project→Profileで位置のみ上書き。
- `D3`: Assetを別テンプレートで共用、更新、欠損、重複SHA256。
- `D4`: schemaVersionが旧／未来／壊れた値のデータ。
- `D5`: 連番の同時出力、キャンセル、失敗後再試行。
- `D6`: パーティクルの同一seed・同一frame→再保存→同じ描画。

## 5. エラー注入
- 外部フォント404、Canvas/CORS違反、不正SVG、壊れたJSON、DBへの書き込み失敗、容量超過模擬、GPUコンテキスト喪失、ZIPインポート途中エラー、保存直後の再起動。
- 失敗を意図的に作ったテストで使ったフラグやfixtureは、本番で誤発動しないよう開発者向け設定に隔離する。

## 6. 画像ゴールデンの保存
- 固定サイズ・固定フォント・固定シード・固定環境で取得。
- `golden/<browser-family>/<case-id>.png`に置き、生成環境を隣のJSONへ記録。
- 作品画像・第三者のライセンス不明画像を自動テストへ同梱しない。
